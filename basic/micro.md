# Micro Text Editor
Breve tutorial para configuração do Micro Text Editor
## Settings
In micro, your settings are stored in `~/.config/micro/settings.json`, a file that is created the first time you run micro.

1. Press Crl-e to go to command mode.

2. Split the editor to another file Press Ctrl-e `> vsplit filename` for vertica split or `> hsplit filename` for horizontal split.
